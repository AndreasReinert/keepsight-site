はじめに

アクセス許可、ジンバルの接続、最初のトラッキング。

アクセス許可

初回起動時にiPhoneがアクセスの許可を求めます。Keepsightは、それぞれ必要になったときにだけ求めます。

アクセス用途
カメラ被写体の検出と撮影。カメラなしではアプリは動作しません。
Bluetoothジンバルの操作。
写真撮影したものの保存とギャラリーでの表示。「制限付きアクセス」で十分です。
マイクビデオの音声と音声コマンド。
音声認識音声コマンドのみ。

アクセスを拒否した場合は、あとで設定 → Keepsightから許可できます。

ジンバルの接続

  • Apple DockKit対応のジンバルまたはスタンド：メーカーの説明に従って、一度iPhoneとペアリングします。以後は、iPhoneを取り付けるとKeepsightが自動で接続します。
  • FeiyuTech AK4500 Beta：ジンバルの電源を入れ、Keepsightの右下にある接続をタップします。

接続されると、ボタンが追尾に変わります。詳しくは対応ジンバルの章をご覧ください。

ジンバルが自由に回転できるようにしてください。指、ケーブル、物を可動範囲に入れないでください。

最初のトラッキング

  1. 左のパネルを開き、被写体人物を選びます。
  2. カメラの前に立ちます。あなたの周りに枠が表示され、左上のステータスが「ターゲットをロック」になります。
  3. 追尾をタップします。ジンバルがあなたを追います。
  4. 停止でトラッキングを終了します。

ジンバルが被写体に向かわず逆に離れていく場合は、すべての設定 → 方向で軸を反転します。
