入門

許可權、連線雲臺、第一次追蹤。

許可權

首次啟動時，iPhone 會請求訪問許可權。Keepsight 只在需要時才逐項請求。

許可權用途
相機檢測並拍攝物件。沒有相機，App 無法工作。
Bluetooth控制雲臺。
照片儲存拍攝內容並在相簿中顯示。“有限訪問”即可。
麥克風影片的聲音和語音指令。
語音識別僅用於語音指令。

如果你拒絕了某項許可權，之後可以在設定 → Keepsight中允許。

連線雲臺

  • 支援 Apple DockKit 的雲臺或支架：按廠商說明將裝置與 iPhone 配對一次。之後，裝上 iPhone 時 Keepsight 會自動連線。
  • FeiyuTech AK4500：開啟雲臺電源，在 Keepsight 右下角輕點 連線。

連線後，按鈕會變為 追蹤。詳情見支援的雲臺一章。

雲臺必須能自由轉動。請讓手指、線纜和物品遠離其活動範圍。

第一次追蹤

  1. 開啟左側面板，選擇拍攝物件 人物。
  2. 站到鏡頭前。你周圍會出現一個框，左上角的狀態顯示“目標已鎖定”。
  3. 輕點 追蹤。雲臺會跟隨你。
  4. 停止 結束追蹤。

如果雲臺背離拍攝物件而不是轉向它，請在 所有設定 → 方向 中反轉該軸。
