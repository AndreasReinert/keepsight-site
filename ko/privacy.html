최종 업데이트: 2026년 11월 16일. Keepsight iOS 앱과 이 웹사이트에 적용됩니다.

요약: Keepsight는 사용자에 대한 데이터를 수집하지 않습니다. 계정, 광고, 추적, 분석 도구가 없습니다. 카메라 화면, 감지, 사진, 비디오는 iPhone에 남습니다.

2. 앱이 처리하는 것

앱은 기능을 제공하기 위해서만, 사용자의 기기에서만 데이터를 처리합니다. 제공자인 저는 그 어떤 것도 받지 않습니다.

  • 카메라: 피사체를 감지하고 따라가기 위해 카메라 화면을 iPhone에서 분석합니다. 이미지는 기기를 벗어나지 않습니다.
  • 얼굴: 얼굴, 미소, 시선 방향을 감지하기 위해 앱이 iPhone에서 카메라 화면을 분석합니다. 누구인지 식별하지 않으며 얼굴 특징을 저장하지 않습니다. 인물 사진에는 전면 카메라의 심도 데이터가 들어 있으며, 이는 사용자가 직접 저장하는 사진 안에만 존재합니다.
  • 마이크: 비디오의 소리를 위해, 그리고 음성 제어를 켠 경우 음성 명령을 위해.
  • 음성 인식: 음성 명령은 Apple의 음성 인식으로 인식됩니다. iPhone과 선택한 언어가 지원하면 기기에서 처리됩니다. 그렇지 않으면 인식을 위해 오디오가 Apple로 전송되며 Apple의 개인정보 처리방침이 적용됩니다. 음성 제어는 기본적으로 꺼져 있습니다.
  • 사진: 앱은 촬영물을 사진 보관함에 저장하고, 갤러리에는 Keepsight로 찍은 촬영물만 표시합니다. iCloud 사진을 사용하면 Apple이 iCloud 설정에 따라 전송합니다.
  • Bluetooth: 짐벌 제어를 위해. 짐벌과는 제어 명령과 상태 값만 주고받습니다.
  • 위치와 비행 데이터: 비행 데이터 오버레이를 켜고 동의한 경우에만 사용합니다. 이때 Keepsight는 지역을 판단하고 화면 속 항공기를 식별하기 위해 iPhone에서 위치를 사용합니다. 비행 데이터는 로컬 네트워크에 있는 사용자의 ADS-B 수신기에서 옵니다. 위치도 비행 데이터도 iPhone 밖으로 나가지 않습니다. 이 기능을 쓰지 않으면 앱은 위치를 사용하지 않습니다.
  • 로컬 네트워크: 비행 데이터 오버레이를 위해서만, 사용자의 ADS-B 수신기에 연결하는 데 사용합니다. Keepsight는 수신기에서 데이터를 받기만 합니다.
  • 설정: 앱 내 설정은 iPhone에만 로컬로 저장됩니다.

3. 구매

‘Keepsight Pro’ 구매는 App Store를 통해 Apple이 처리합니다. 저는 결제 정보, 이름, 이메일 주소를 받지 않으며, Apple로부터 집계된 판매 수치만 받습니다.

4. 테스트 버전(TestFlight)

TestFlight로 테스트 버전을 사용하면 Apple이 초대를 위해 이메일 주소를 처리하고, 동의한 경우 충돌 보고서와 피드백을 처리합니다. 저는 문제를 고치기 위해 피드백과 충돌 보고서를 보며, 제가 직접 초대한 테스터의 이메일 주소를 봅니다.

5. 이메일 문의

메일을 보내 주시면 이메일 주소와 메시지 내용은 답장에만 사용합니다. 문제가 해결되면 메시지를 삭제하며, 늦어도 2년 뒤에는 삭제합니다.

6. 이 웹사이트

이 웹사이트는 쿠키를 설정하지 않고 추적도 하지 않습니다. 글꼴과 스크립트는 같은 사이트에서 제공되며 제3자 콘텐츠는 불러오지 않습니다. 언어 선택은 브라우저에만 저장됩니다. 사이트는 GitHub Pages(GitHub, Inc., 미국)에서 호스팅됩니다. 방문 시 GitHub가 IP 주소처럼 기술적으로 필요한 데이터를 서버 로그에서 처리합니다. 자세한 내용은 GitHub의 개인정보 보호정책을 참고하세요.

7. 사용자의 권리

스위스 데이터 보호법과, 해당하는 경우 GDPR에 따라 열람, 정정, 삭제, 처리 제한, 데이터 이동의 권리와 감독 기관(스위스에서는 FDPIC)에 불만을 제기할 권리가 있습니다. 앱은 저에게 데이터를 보내지 않으므로 실제로는 사용자가 저에게 보낸 이메일에만 해당합니다. ar.orca@gmail.com으로 연락해 주세요.

8. 어린이

이 앱은 어린이를 대상으로 하지 않으며 어린이의 데이터를 수집하지 않습니다.

9. 변경

앱이 바뀌어 이 방침의 변경이 필요해지면 여기에서 업데이트합니다. 이 페이지의 버전이 적용됩니다.
