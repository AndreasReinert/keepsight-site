가상 짐벌

부드럽게 따라가며 줌하는 프레임의 두 번째 비디오.

가상 짐벌은 전체 카메라 화면에서 피사체를 따라가며 스스로 줌하는 프레임을 잘라 냅니다. 결과물은 완성된 차분한 비디오이며 녹화 직후 바로 쓸 수 있습니다.

켜기

  1. 오른쪽 패널을 열고 가상 짐벌을 켜세요.
  2. 피사체를 선택하세요. 뷰파인더에 프레임이 밝은 윤곽으로 보이고 바깥 영역은 어두워집니다.
  3. 녹화를 시작하세요.

실제 짐벌은 필요 없습니다. iPhone을 손에 들거나 삼각대에 올려도 됩니다. 짐벌과 자동 줌을 함께 쓰면 화면이 더욱 안정됩니다.

설정

조절 항목효과
피사체 주변 여백10~40퍼센트. 여백이 많으면 차분해 보이고, 적으면 피사체가 더 가까워집니다.
최대 줌1.5×~4×. 4K로 녹화하면 2×까지는 선명도가 그대로 유지됩니다.
부드러움프레임이 얼마나 느긋하게 따라가는지. 값이 클수록 더 부드러워집니다.
원본도 저장잘라 낸 비디오와 함께 전체 비디오도 저장합니다.

저장되는 것

  • 1080p의 잘라 낸 비디오.
  • 선택 사항: 선택한 해상도의 원본.

Keepsight가 피사체를 놓치면 프레임은 천천히 전체 화면으로 돌아갑니다.

가상 짐벌은 피사체를 프레임 안에서 안정적으로 유지합니다. 배경의 심한 흔들림은 보정하지 않습니다.
