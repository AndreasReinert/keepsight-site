비행 데이터

사용자의 ADS-B 수신기에서 받은 실시간 비행 데이터를 영상에: 필요한 것, 작동하는 곳, 개인정보 보호.

사용 가능 여부: 실시간 비행 데이터는 승인된 국가와 지역에서만 사용할 수 있으며 사용자의 ADS-B 수신기가 필요합니다. 현재 승인된 지역이 없으므로 이 기능은 모든 곳에서 꺼져 있습니다.

비행 데이터 오버레이를 사용하면 Keepsight가 추적 중인 여객기의 편명, 고도, 속도를 뷰파인더와 iPhone이 녹화하는 영상에 표시합니다. 데이터는 같은 Wi-Fi에 있는 사용자의 ADS-B 수신기에서 옵니다. 인터넷이나 비행 데이터 제공업체는 관여하지 않습니다.

Keepsight는 수신기 없이도 화면을 보고 항공기를 따라갑니다. 수신기는 오버레이에만 필요하며 앱에 포함되지 않습니다. 별도로 구입하거나 직접 조립해야 합니다.

필요한 것

  • 수신기: Stratux(예: 1090 MHz USB 수신 스틱과 안테나를 단 Raspberry Pi 3) 또는 Wi-Fi로 GDL90을 보내는 다른 기기.
  • 스틱만으로는 안 됩니다: FlightAware Pro Stick 같은 USB 수신 스틱에는 Stratux를 실행하는 Raspberry Pi 같은 호스트가 필요합니다. 표준 PiAware 설치는 FlightAware로 데이터를 전송하므로 적합하지 않습니다.
  • 같은 Wi-Fi: iPhone을 수신기의 Wi-Fi에 연결합니다. 이 네트워크에는 보통 인터넷이 없지만 괜찮습니다.
  • 승인된 지역: 데이터를 직접 수신한다고 해서 그것만으로 해당 국가에서 이 기능이 허용되는 것은 아닙니다.

Stratux 또는 GDL90

수신기연결Keepsight로 테스트됨
Stratux (JSON)수신기로의 WebSocket 연결, 보통 192.168.10.1아직 아님
GDL90 (UDP)수신기가 iPhone의 포트 4000으로 전송아직 아님

둘 다 프로토콜 수준에서 지원합니다. 지금까지 실제 하드웨어에서 Keepsight로 테스트한 수신기는 없으며, SkyEcho 2 같은 기기는 다르게 동작할 수 있습니다. FLARM으로만 송신되는 항공기는 지원하지 않습니다.

켜기

  1. 설정을 열고 비행 데이터 오버레이(ADS-B)를 켜세요.
  2. 안내를 읽고 동의 및 활성화을 탭하세요. 그런 다음에야 iOS가 위치를 묻습니다.
  3. 수신기의 Wi-Fi에 연결하고 수신기 종류를 선택한 다음 주소를 입력하세요. iOS가 로컬 네트워크 접근 권한을 한 번 묻습니다.
  4. 수신기 연결를 탭하세요. Keepsight는 절대 스스로 연결하지 않습니다.
  5. 피사체로 비행기를 선택하고 카메라를 항공기에 향하게 하세요.

카메라가 보는 방향에 여러 항공기가 해당하면 Keepsight는 추측하지 않습니다. 항공기 선택 필요를 탭하고 맞는 것을 고르세요.

항공기는 그 시점에 수신 중인 여객기 목록에서 항상 직접 선택합니다. 목록에는 각 위치 정보가 몇 초 전의 것인지 표시됩니다.

설정에 연결 상태가 표시됩니다: 연결 중, 항공기 없이 연결됨, 수신 중 또는 데이터가 오래됨. 다시 연결를 누르면 연결을 다시 시작합니다.

비행 데이터 설정은 비행기가 피사체로 선택되어 있는 동안에만 나타납니다.

Keepsight에 위치가 필요한 이유

iOS는 비행 데이터 오버레이를 켜고 동의할 때만 위치를 묻습니다. Keepsight에 위치가 필요한 이유는 두 가지입니다.

  • 지역 확인: 비행 데이터를 표시할 수 있는지는 사용자가 있는 국가에 따라 달라집니다. Keepsight는 iPhone이 실제로 있는 곳을 기준으로 기기에서 직접 판별합니다.
  • 화면 속 항공기 식별: Keepsight는 사용자로부터 각 항공기까지의 방향과 지평선 위 각도를 계산해 카메라가 향하는 방향과 비교합니다. 나침반도 진북을 찾으려면 위치가 필요합니다.

장소를 직접 입력하는 방법은 제공하지 않습니다. 그러면 지역 확인을 더 이상 신뢰할 수 없기 때문입니다. 비행 데이터를 사용하지 않으면 Keepsight는 위치를 절대 묻지 않습니다.

작동하는 곳

Keepsight는 현재 위치를 기준으로 iPhone에서 국가를 판별합니다. App Store 국가, 언어, 인터넷 주소는 영향을 주지 않습니다. 국경 근처와 바다에서는 기능이 꺼진 상태로 유지됩니다.

모든 국가는 승인 전에 개별적으로 검토됩니다. 그때까지 앱은 사용자의 지역에서 실시간 비행 데이터를 사용할 수 없다고 알려 줍니다. 트래킹과 녹화는 평소처럼 작동합니다.

iPhone 밖으로 나가는 것

없습니다. Keepsight는 수신기의 데이터를 받기만 하며 수신기 설정을 바꾸지 않습니다. 위치도 비행 데이터도 서버로 전송되지 않습니다.

비행 데이터는 수신기가 연결되어 있는 동안에만 iPhone의 메모리에 존재합니다. 연결을 끊거나 다른 피사체를 선택하거나 앱을 떠나면 삭제됩니다. 아무것도 저장되거나 백업되지 않습니다.

표시

비행 데이터는 알려진 항공사의 정기 여객편과 화물편에 대해서만 표시됩니다. 개인, 비즈니스, 군용, 정부 항공기는 절대 표시되지 않으며, 항공기의 등록 부호와 ICAO 주소도 표시되지 않습니다.

기종은 ADS-B에 포함되지 않으므로 표시되지 않습니다. OGN, FLARM, TIS-B처럼 수신기가 단순히 전달하는 데이터도 절대 표시하지 않습니다.

모서리, 간략 또는 상세 보기, 미터법 또는 야드파운드법 단위를 선택하세요. 15초보다 오래된 데이터는 멈춰 있는 대신 숨겨집니다. 비행 데이터가 들어간 모든 영상에는 “Flight data: Local ADS-B”라는 문구가 표시됩니다.

오버레이는 iPhone으로 녹화한 비디오에 기록됩니다. 짐벌 위의 카메라는 자체적으로 녹화하며 오버레이가 들어가지 않습니다.

원하면 선택한 항공기가 아직 화면에 보이지 않는 동안 Keepsight가 보고된 위치 쪽으로 짐벌을 돌립니다. 정확도는 나침반에 좌우됩니다.

정확도

비행 데이터는 지연되거나 불완전하거나 잘못될 수 있습니다. 정보 제공 목적일 뿐이며 항법, 비행 안전 또는 운항상의 결정에는 적합하지 않습니다.
