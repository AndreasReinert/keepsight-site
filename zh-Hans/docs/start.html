入门

权限、连接云台、第一次追踪。

权限

首次启动时，iPhone 会请求访问权限。Keepsight 只在需要时才逐项请求。

权限用途
相机检测并拍摄对象。没有相机，App 无法工作。
Bluetooth控制云台。
照片保存拍摄内容并在图库中显示。“有限访问”即可。
麦克风视频的声音和语音指令。
语音识别仅用于语音指令。
位置仅用于实时航班数据：确认你所在的地区并识别飞机。只保留在 iPhone 上。
本地网络仅用于实时航班数据：连接你自己的 ADS-B 接收机。

如果你拒绝了某项权限，之后可以在设置 → Keepsight中允许。

连接云台

  • 支持 Apple DockKit 的云台或支架：按厂商说明将设备与 iPhone 配对一次。之后，装上 iPhone 时 Keepsight 会自动连接。
  • FeiyuTech AK4500：打开云台电源，在 Keepsight 右下角轻点 连接。

连接后，按钮会变为 跟踪。详情见支持的云台一章。

云台必须能自由转动。请让手指、线缆和物品远离其活动范围。

第一次追踪

  1. 打开左侧面板，选择拍摄对象 人物。
  2. 站到镜头前。你周围会出现一个框，左上角的状态显示“目标已锁定”。
  3. 轻点 跟踪。云台会跟随你。
  4. 停止 结束追踪。

如果云台转向背离主体而不是朝向主体，Keepsight 会在片刻后察觉并自动反转方向。你也可以在 所有设置 → 方向 中反转某个轴。
