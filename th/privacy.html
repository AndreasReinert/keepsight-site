2. สิ่งที่แอปประมวลผล

แอปประมวลผลข้อมูลบนอุปกรณ์ของคุณเท่านั้น และเพื่อให้บริการฟีเจอร์ของแอปเท่านั้น ผมในฐานะผู้ให้บริการไม่ได้รับข้อมูลใดเลย

  • กล้อง: ภาพจากกล้องถูกวิเคราะห์บน iPhone เพื่อตรวจจับและตามตัวแบบ ภาพไม่ออกจากอุปกรณ์
  • ใบหน้า: เพื่อตรวจจับใบหน้า รอยยิ้ม และทิศที่คนมอง แอปวิเคราะห์ภาพจากกล้องบน iPhone แอปไม่ระบุว่าใครเป็นใครและไม่เก็บลักษณะใบหน้า ภาพบุคคลมีข้อมูลความลึกจากกล้องหน้า ซึ่งมีอยู่เฉพาะในภาพที่คุณบันทึกเองเท่านั้น
  • ไมโครโฟน: สำหรับเสียงของวิดีโอ และสำหรับคำสั่งเสียงหากคุณเปิดการควบคุมด้วยเสียง
  • การรู้จำเสียงพูด: คำสั่งเสียงถูกรู้จำโดยการรู้จำเสียงพูดของ Apple หาก iPhone และภาษาที่เลือกรองรับ การรู้จำจะทำบนอุปกรณ์ มิฉะนั้นเสียงจะถูกส่งไปยัง Apple เพื่อรู้จำ ภายใต้นโยบายความเป็นส่วนตัวของ Apple การควบคุมด้วยเสียงปิดอยู่ตามค่าเริ่มต้น
  • รูปภาพ: แอปบันทึกสิ่งที่คุณถ่ายลงในคลังรูปภาพ และแสดงในแกลเลอรีเฉพาะสิ่งที่ถ่ายด้วย Keepsight หากคุณใช้รูปภาพ iCloud Apple จะถ่ายโอนตามการตั้งค่า iCloud ของคุณ
  • บลูทูธ: เพื่อควบคุมกิมบอลของคุณ มีการแลกเปลี่ยนเฉพาะคำสั่งควบคุมและค่าสถานะกับกิมบอล
  • ตำแหน่งและข้อมูลเที่ยวบิน: เฉพาะเมื่อคุณเปิดการแสดงข้อมูลเที่ยวบินและยินยอมเท่านั้น จากนั้น Keepsight จะใช้ตำแหน่งของคุณบน iPhone เพื่อระบุภูมิภาคและระบุเครื่องบินในภาพ ข้อมูลเที่ยวบินมาจากเครื่องรับ ADS-B ของคุณเองในเครือข่ายภายใน ทั้งตำแหน่งของคุณและข้อมูลเที่ยวบินจะไม่ออกจาก iPhone หากไม่ใช้ฟีเจอร์นี้ แอปจะไม่ใช้ตำแหน่งของคุณ
  • เครือข่ายภายใน: เฉพาะสำหรับการแสดงข้อมูลเที่ยวบิน เพื่อเข้าถึงเครื่องรับ ADS-B ของคุณเอง Keepsight เพียงรับข้อมูลจากเครื่องรับเท่านั้น
  • การตั้งค่า: การตั้งค่าในแอปของคุณเก็บไว้ในเครื่อง iPhone เท่านั้น

3. การซื้อ

การซื้อ “Keepsight Pro” ดำเนินการโดย Apple ผ่าน App Store ผมไม่ได้รับรายละเอียดการชำระเงิน ชื่อ หรือที่อยู่อีเมล ได้รับเพียงตัวเลขยอดขายรวมจาก Apple

4. เวอร์ชันทดสอบ (TestFlight)

หากคุณใช้เวอร์ชันทดสอบผ่าน TestFlight Apple จะประมวลผลที่อยู่อีเมลของคุณเพื่อส่งคำเชิญ และหากคุณยินยอม จะประมวลผลรายงานข้อขัดข้องและความคิดเห็นของคุณ ผมเห็นความคิดเห็นและรายงานข้อขัดข้องเพื่อแก้ปัญหา และเห็นที่อยู่อีเมลของผู้ทดสอบที่ผมเชิญเอง

5. การติดต่อทางอีเมล

หากคุณเขียนถึงผม ผมใช้ที่อยู่อีเมลและเนื้อหาข้อความของคุณเพื่อตอบกลับเท่านั้น ผมลบข้อความเมื่อเรื่องเสร็จสิ้น อย่างช้าที่สุดหลังสองปี

6. เว็บไซต์นี้

เว็บไซต์นี้ไม่ตั้งคุกกี้และไม่ใช้การติดตาม ฟอนต์และสคริปต์ให้บริการจากเว็บไซต์เดียวกัน ไม่มีการโหลดเนื้อหาจากบุคคลที่สาม ภาษาที่คุณเลือกเก็บไว้ในเบราว์เซอร์ของคุณเท่านั้น เว็บไซต์โฮสต์บน GitHub Pages (GitHub, Inc. สหรัฐอเมริกา) เมื่อคุณเข้าชม GitHub ประมวลผลข้อมูลที่จำเป็นทางเทคนิค เช่น ที่อยู่ IP ของคุณในบันทึกเซิร์ฟเวอร์ ดูรายละเอียดในคำชี้แจงสิทธิ์ส่วนบุคคลของ GitHub

7. สิทธิ์ของคุณ

ภายใต้กฎหมายคุ้มครองข้อมูลของสวิตเซอร์แลนด์ และ GDPR ในกรณีที่ใช้บังคับ คุณมีสิทธิ์ในการเข้าถึง แก้ไข ลบ จำกัดการประมวลผล และโอนย้ายข้อมูล รวมถึงสิทธิ์ร้องเรียนต่อหน่วยงานกำกับดูแล (ในสวิตเซอร์แลนด์คือ FDPIC) เนื่องจากแอปไม่ส่งข้อมูลให้ผม ในทางปฏิบัติจึงเกี่ยวข้องเฉพาะอีเมลที่คุณส่งถึงผม เขียนถึง ar.orca@gmail.com
