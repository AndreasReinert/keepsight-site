Stabilisateur virtuel

Un cadrage qui suit en douceur, en 2K avec Keepsight Pro.

Le stabilisateur virtuel découpe dans l’image complète un cadrage qui suit le sujet. Le cadrage garde sa taille, l’image reste donc calme. La vidéo est prête dès la fin de l’enregistrement.

Activer

  1. Touchez le symbole du stabilisateur dans la barre du bas jusqu’à ce qu’il soit vert et indique Virtuel.
  2. Choisissez un sujet. Dans le viseur, le cadre apparaît comme un contour clair ; la zone extérieure est assombrie.
  3. Lancez l’enregistrement.

Un vrai stabilisateur n’est pas nécessaire. Vous pouvez tenir l’iPhone à la main ou le poser sur un trépied. Dès qu’un stabilisateur est connecté, le stabilisateur virtuel se met en pause : le stabilisateur suit et l’image complète est enregistrée.

Réglages

RéglageEffet
Doux, Standard, SportLa vitesse à laquelle le cadrage suit, dans le panneau de droite de la vue complète.
Enregistrer aussi l’originalEnregistre la vidéo complète en plus de la vidéo recadrée.

Ce qui est enregistré

  • La vidéo cadrée : en 2K (2560 × 1440) avec Keepsight Pro si vous filmez en 4K, sinon en 1080p.
  • En option, l’original dans la définition choisie.

Si Keepsight perd le sujet, le cadrage revient lentement au centre. Si le sujet n’y tient plus, le cadrage s’élargit.

Le stabilisateur virtuel convient quand on bouge peu : vlogs, cuisine ou entraînement sur place. Si vous vous déplacez dans la pièce, utilisez un stabilisateur.

Stabilisation d’image

Keepsight utilise la stabilisation d’image d’iOS pour les vidéos : un niveau renforcé avec le stabilisateur virtuel, le niveau standard sinon. Vous pouvez la désactiver sous Tous les réglages.
