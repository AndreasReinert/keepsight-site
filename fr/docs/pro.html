Gratuit et Pro

Ce que fait la version gratuite, ce que débloque Pro, achat et restauration.

La version gratuite sert à essayer : vous testez le suivi, les gestes et l’appareil photo sur des personnes avant de payer quoi que ce soit.

Essayer le suivi Pro

Touchez un sujet verrouillé dans le panneau de suivi et choisissez Démarrer l'essai. Pendant 60 secondes, Keepsight suit ce sujet exactement comme la version Pro. Vous disposez de trois sessions ; une session qui échoue dans les premières secondes ne compte pas.

Dans la version gratuite, une vidéo s'arrête d'elle-même après 60 secondes. Un message apparaît 10 secondes avant la fin.

Acheter Pro

Touchez PRO en haut à droite, puis Débloquer. Pro est un achat unique sans abonnement. L’App Store affiche le prix dans votre devise et Apple gère le paiement.

Restaurer un achat

Sur un nouvel iPhone ou après une réinstallation, touchez PRO → Restaurer l’achat. Vous devez être connecté avec le même compte Apple que lors de l’achat.

Vous avez un code pour Keepsight Pro ? Touchez PRO → Utiliser un code et saisissez-le. Apple vérifie le code ; il débloque Pro comme un achat.

Remboursements

Demandez un remboursement à Apple sur reportaproblem.apple.com.
