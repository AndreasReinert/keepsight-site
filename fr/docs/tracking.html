Suivre des sujets

Types de sujets, cible personnalisée, vitesse et comportement quand le sujet est masqué.

Choisir un sujet

Dans le panneau de gauche, vous choisissez ce que Keepsight doit chercher.

SujetVersionRemarque
PersonneGratuitLe corps entier. Idéal pour le sport et le mouvement.
VisageGratuitPour les gros plans, les vlogs et les selfies. Keepsight vise les yeux : c’est la ligne des yeux qui se trouve au centre de l’image, pas le nez.
AvionProFonctionne le mieux dans le ciel avec le téléobjectif.
OiseauPro
AnimalProChiens, chats, chevaux et autres.
VéhiculeProVoitures, motos, bus, camions.
TrainPro
BateauPro

Si plusieurs sujets correspondants sont dans l’image, Keepsight prend le plus proche du centre. Touchez un autre cadre pour changer.

Activer et désactiver la détection

La détection demande de la puissance de calcul et chauffe l’iPhone. Keepsight ne calcule donc que le nécessaire :

  • Plein régime : tant que le suivi, le zoom automatique, le gimbal virtuel, le déclenchement automatique, les gestes ou une cible personnalisée ont besoin de la détection.
  • Aperçu : sinon environ cinq images par seconde, pour que vous voyiez les cadres et puissiez choisir une cible.
  • Désactivée : le commutateur Détection en haut du panneau Suivi la coupe complètement. Elle démarre d’elle-même dès qu’une des fonctions ci-dessus en a besoin.

Le cadre vert reste toujours dans l’image visible, même quand le sujet est plus grand que la vue.

Cible personnalisée

Si vous tracez un cadre autour d’un objet, Keepsight suit exactement cet objet, quel que soit le type de sujet. Le panneau de gauche affiche alors le bouton Cible personnalisée. Touchez-le pour annuler la sélection.

Vitesse

ProfilComportement
DouxDémarrage en douceur, moitié de la vitesse maximale, les petits mouvements sont ignorés. Pour des plans calmes.
StandardÉquilibré. Le bon point de départ pour la plupart des sujets.
SportRéagit le plus vite. Pour les changements de direction rapides.
PersoVous réglez vous-même toutes les valeurs du régulateur, voir le chapitre Réglages.

Quand le sujet disparaît

  • Prédiction : si le sujet est masqué brièvement, le gimbal continue de panoramiquer dans la même direction. Vous réglez la durée dans Tous les réglages ; la valeur par défaut est de 1,5 seconde.
  • Cible perdue : ensuite, le gimbal s’arrête jusqu’à ce que le sujet soit de nouveau détecté.
