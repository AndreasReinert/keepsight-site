Kebijakan Privasi

Terakhir diperbarui: 15 November 2026. Berlaku untuk aplikasi iOS Keepsight dan situs web ini.

Singkatnya: Keepsight tidak mengumpulkan data tentang Anda. Tidak ada akun, iklan, pelacakan, maupun analitik. Gambar kamera, deteksi, foto, dan video tetap di iPhone Anda. Satu-satunya pengecualian adalah fitur data penerbangan yang opsional, yang mengirim lokasi perkiraan ke penyedia data (lihat bagian 2).

2. Apa yang diproses aplikasi

Aplikasi memproses data hanya di perangkat Anda dan hanya untuk menyediakan fiturnya. Saya, sebagai penyedia, tidak menerima apa pun darinya.

  • Kamera: Gambar kamera dianalisis di iPhone untuk mendeteksi dan mengikuti subjek. Gambar tidak meninggalkan perangkat.
  • Wajah: untuk mendeteksi wajah, senyum, dan arah pandang orang, aplikasi menganalisis gambar kamera di iPhone. Aplikasi tidak mengenali siapa seseorang dan tidak menyimpan ciri wajah. Foto potret berisi data kedalaman dari kamera depan; data itu hanya ada di foto yang Anda simpan sendiri.
  • Mikrofon: untuk suara video Anda dan, jika Anda menyalakan kendali suara, untuk perintah suara.
  • Pengenalan ucapan: Perintah suara dikenali oleh pengenalan ucapan Apple. Jika iPhone Anda dan bahasa yang dipilih mendukungnya, ini terjadi di perangkat. Jika tidak, audio dikirim ke Apple untuk dikenali, tunduk pada kebijakan privasi Apple. Kendali suara mati secara bawaan.
  • Foto: Aplikasi menyimpan jepretan Anda ke perpustakaan foto dan di galerinya hanya menampilkan jepretan yang dibuat dengan Keepsight. Jika Anda memakai Foto iCloud, Apple mentransfernya sesuai pengaturan iCloud Anda.
  • Bluetooth: untuk mengendalikan gimbal Anda. Hanya perintah kendali dan nilai status yang dipertukarkan dengan gimbal.
  • Lokasi dan data penerbangan: hanya jika Anda mengaktifkan overlay data penerbangan dan menyetujuinya. Keepsight kemudian menggunakan lokasi Anda di iPhone untuk menentukan wilayah dan mengenali pesawat di dalam gambar. Data penerbangan berasal dari penerima ADS-B milik Anda di jaringan lokal. Lokasi Anda maupun data penerbangan tidak keluar dari iPhone. Tanpa fitur ini, aplikasi tidak menggunakan lokasi Anda.
  • Jaringan lokal: hanya untuk overlay data penerbangan, guna menjangkau penerima ADS-B milik Anda. Keepsight hanya menerima data darinya.
  • Pengaturan: Pengaturan Anda di aplikasi hanya disimpan secara lokal di iPhone.

3. Pembelian

Pembelian “Keepsight Pro” ditangani Apple melalui App Store. Saya tidak menerima rincian pembayaran, nama, atau alamat email, hanya angka penjualan agregat dari Apple.

4. Versi uji (TestFlight)

Jika Anda memakai versi uji melalui TestFlight, Apple memproses alamat email Anda untuk undangan dan, jika Anda setuju, laporan kerusakan serta masukan Anda. Saya melihat masukan dan laporan kerusakan untuk memperbaiki masalah, serta alamat email penguji yang saya undang sendiri.

5. Kontak melalui email

Jika Anda menulis kepada saya, saya memakai alamat email dan isi pesan Anda hanya untuk membalas. Saya menghapus pesan setelah urusannya selesai, paling lambat setelah dua tahun.

6. Situs web ini

Situs web ini tidak memasang cookie dan tidak memakai pelacakan. Fon dan skrip disajikan dari situs yang sama; tidak ada konten pihak ketiga yang dimuat. Pilihan bahasa Anda hanya disimpan di browser Anda. Situs ini dihosting di GitHub Pages (GitHub, Inc., AS). Saat Anda berkunjung, GitHub memproses data yang diperlukan secara teknis seperti alamat IP Anda di log server. Lihat pernyataan privasi GitHub untuk rinciannya.

7. Hak Anda

Berdasarkan Undang-Undang Perlindungan Data Swiss dan, jika berlaku, GDPR, Anda berhak atas akses, perbaikan, penghapusan, pembatasan pemrosesan, dan portabilitas data, serta berhak mengajukan keluhan kepada otoritas pengawas (di Swiss, FDPIC). Karena aplikasi tidak mengirim data kepada saya, dalam praktiknya ini hanya menyangkut email yang Anda kirim kepada saya. Tulis ke ar.orca@gmail.com.

8. Anak-anak

Aplikasi ini tidak ditujukan untuk anak-anak dan tidak mengumpulkan data dari mereka.
